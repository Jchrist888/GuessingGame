# GuessingGame

Un jeu de devinettes simple en Java.

## Ce que fait le programme

- Génère un nombre secret aléatoire entre 1 et 100
- Demande à l'utilisateur de deviner le nombre
- Indique si la proposition est trop grande ou trop petite
- L'utilisateur a 10 essais maximum

## Les fichiers

- `Main.java` : contient tout le code du jeu

## Comment l'utiliser

1. Ouvrir le projet dans IntelliJ
2. Lancer `Main.java`
3. Entrer un nombre entre 1 et 100 et appuyer sur Entrée

## Exemple de partie

```
=== Jeu de devinettes ===
Trouve le nombre secret entre 1 et 100.
Tu as 10 essais. Bonne chance !
=========================

Essai 1/10 : 50
Trop grand ! Essaie un nombre plus petit.

Essai 2/10 : 25
Trop petit ! Essaie un nombre plus grand.

Essai 3/10 : 37
Bravo ! Tu as gagne en 3 essai(s) !
```
